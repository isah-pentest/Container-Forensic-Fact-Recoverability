# Gate G5 — statistical freeze (in progress)

Blueprint v3.0, Sections 8.2, 12.5, 16, 18, 22.2. Everything below is written before the
simulation it governs is run.

## Decisions fixed before any power simulation (2026-10-27)
- Scenarios: `protocol/power/scenarios.json`.
  - pilot_informed = G4 pilot cell rates (LC 3/3, LD 3/3, MC 3/3, MD 1/3).
  - conservative = each pilot cell moved 0.05 toward the pooled mean (0.833), the common cell value
    under the null: LC/LD/MC 0.95, MD 0.383.
  - formula_predicted = 0.98 / 0.98 / 0.98 / 0.50 (Section 4 at the G3 operating points).
- Type-I calibration (Section 16: 0.035–0.065 over 2,000 null datasets) is checked at
  `null_calibration` (every cell 0.5). At high common rates most blocks have no contrast and a
  discrete exact test is conservative by construction (type-I well below α), which is not a
  calibration failure; the type-I error at the pilot's pooled level (0.833) is reported alongside.
- Search: B ∈ {6, 8, 10, 12, 14, 16, 20, 24}, σ_b ∈ {0, 0.5, 1.0}, 1,000 datasets × 1,000 sign
  draws (exact when B ≤ 9), seed 20261027 → `protocol/power/search.csv`.
- Rule: B = smallest value with power ≥ 0.80 (pilot_informed, σ_b = 0.5) and ≥ 0.70
  (conservative, σ_b = 0.5); B ≤ 24, else H1 is withdrawn.
- Confirmation at the chosen B: 2,000 datasets × 2,000 draws for pilot_informed and conservative
  (σ_b = 0.5), and 2,000 datasets for each null → `protocol/power/confirm.json`. If confirmation
  falls below the targets, the next larger B in the grid is confirmed in the same way.
- Master seed: from a NIST Randomness Beacon 2.0 pulse fetched after B is committed;
  seed = first 64 bits of the pulse `outputValue` (hex), recorded with the full pulse in
  `protocol/master_seed.json` before the schedule is generated.
